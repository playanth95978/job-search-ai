L'application n'a pas pu démarrer

Le serveur répond, mais le code de l'interface ne s'est pas chargé. Dans l'ordre :

  1. Rechargez la page : un fichier peut avoir échoué au téléchargement.
  2. Videz le cache du navigateur, puis rechargez.
  3. En développement, vérifiez que le front a bien été construit : npm start ou npm run webapp:build.

Si le problème persiste, la console du navigateur indique le fichier en cause.
